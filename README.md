# TallerSumativo-DSV
Taller sumativo usando como base lo creado en el Taller Práctico.

Se creo una estructura con una card Index de la coordinadora donde se navega a las cards de los otros integrantes.

Estas otras cards se modifican en ramas creadas por cada integrante que se le hace merge al main para que se actualizen los archivos del programa con su información.
