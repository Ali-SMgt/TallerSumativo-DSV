# TallerSumativo-DSV
Taller sumativo usando como base lo creado en el Taller Práctico.

1- Se creo una estructura con una card Index de la coordinadora donde se navega a las cards de los otros integrantes que se almacenan en otros archivos.

Estas otras cards se modifican en ramas creadas por cada integrante que se le hace merge al main para que se actualizen los archivos del programa con su información. Se actualiza el README al hacer una acción de branch.
